# 승인된 화면 시안(인터랙티브 프로토타입)

2026-09-25~26 브레인스토밍에서 사용자가 승인한 최종 시안이다. 브라우저로 파일을 바로 열면 된다
(글꼴·지도 라이브러리·지도 타일은 인터넷에서 불러온다).

| 파일 | 내용 | 원래 이름 |
|---|---|---|
| `hq-prototype.html` | 본사 관제 화면(PC): 전체 지도·왼쪽 목록·오른쪽 현장 상세·하단 시간 스크러버·비구름 레이어 버튼 | `hq-prototype-v7-ci.html` |
| `site-prototype.html` | 현장 화면(휴대폰): 끌어올리는 시트·히어로·24시간·주변 비구름·10일 예보 | `site-prototype-v3-ci.html` |

- 들어 있는 숫자·현장 상황은 시연용 예시다. 실제 자료가 아니다.
- 1~3단계는 이미 `web/`에 구현되어 있고, 구현과 시안이 다르면 **구현(`web/`)과 설계서가 우선**한다.
- 4단계(레이더) 모양 참고: 본사 시안의 비구름 레이어 버튼·범례, 현장 시안의 "주변 비구름" 카드. 동작 기준은 설계서 5.8절.
- 로고는 공식 파일을 그대로 넣은 것이다(가공 금지). 새 시안을 만들 때도 네오현대 글꼴은 넣지 않는다.
