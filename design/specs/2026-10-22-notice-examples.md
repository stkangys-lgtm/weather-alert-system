## 1. 현장권 묶는 규칙(안)

1. 도 지역: 도 약칭 + 시·군 이름(시·군 글자 뺌) + "권". 같은 도의 현장은 `·`로 잇는다 → `강원 태백·화천·영월권`
2. 광역시: `부산권`처럼 시 이름만.
3. 서울·인천·경기: 서울 현장이 함께 있으면 `서울·경기권`, 경기만 있으면 `경기 시흥권`처럼 시 이름까지.
4. 순서는 북→남: 서울·경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주.
5. "특보현황"에서는 **같은 특보를 받은 현장끼리만** 묶는다(같은 도라도 특보가 없거나 다르면 빠지거나 다른 줄).
6. 수치는 묶음 안에서 가장 위험한 값: 한파 = 가장 낮은 기온, 폭염 = 가장 높은 체감온도, 호우 = 가장 많은 시간당 강수.

전 현장 21곳에 적용하면:

| 현장권 | 현장 |
| --- | --- |
| 서울·경기권 | 연희·연남, LX 논현, 반얀트리, 군포복합개발, 렉서스 동탄, 시흥능곡, 송산그린시티 |
| 강원 태백·화천·영월·강릉권 | 청정고원, 화천 군부대, 산솔면, 동해안 자동차길 |
| 충북 진천·충주권 | 진천 신공장, 진천 기숙사, 단월정수장 |
| 전남 목포·곡성권 | 목포 김공장, 뇌죽천 |
| 경북 안동·울진·청도·영주권 | 포항~안동 국도, 후포, 풍각지구, 가흥정수장 |
| 경남 양산권 | 양산 부산대병원 |

## 6. 사용자 확인 질문

1. 현장권 이름: 양산은 `경남 양산권`으로 했다(예전 공지는 `부산권`). 강원·경북처럼 4곳이 묶이면 이름이 길어진다(`경북 안동·울진·청도·영주권`). 이대로 괜찮은지.
2. 한파 ②·③ 초안 문구를 그대로 써도 되는지(샘플이 오면 바꿈).
3. `■ 긴급 공지드립니다.` 머리말은 **경보·중대경보 발효 시**에만 쓰는 안.
4. 호우 "지역별 예상 강수량"(양식의 `30~100mm`)은 단기예보 시간별 값을 더한 근사치라 넣지 않고 "예상 강수시간"만 둔 안.
5. 현장 1곳만 보는 "현장 전파 문안"도 같은 틀(①에 그 현장 1줄)로 맞춘다.
6. 모든 문안 끝(감사합니다 앞)에 `(자료: 기상청)`을 넣는다 — 기상법 제12조의3제5항(2026-09-18 시행): 기상 자료를 공표하거나
   제3자에게 제공할 때 출처를 밝혀야 함(위반 시 과태료). 공개 화면에는 이미 "자료: 기상청"이 늘 보이지만, 복사해 카톡으로 보내는
   문안 본문에는 지금 출처가 없다.
